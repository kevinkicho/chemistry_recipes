# Chemistry Recipes — web app

Next.js 15 application for the Chemistry Recipes process hub.

## Develop

From repo root:

```bash
cp ../.env.example ../.env   # if not already
npm install
npm run dev
```

Or from this directory after root `.env` exists:

```bash
npm install
npm run dev
```

## Tests

```bash
npm test
```

## Notes

- Secrets live in **repo-root** `.env` (gitignored). See [../.env.example](../.env.example).  
- Full documentation: [../README.md](../README.md) and [../docs/](../docs/).
